# VIC-222 plan: control active session time

1. Persist accumulated active milliseconds and the start of the current running interval. Pausing closes that interval; resuming starts a new one.
2. Give new sessions an active clock. Migrate older sessions with an unknown clock, without guessing how long their open interval was active.
3. For an older active session, require the user to enter the active minutes they know before timing can resume or the session can finish. A paused newer session also permits an explicit correction when it was accidentally left running.
4. Show active time in the workout and summary, excluding paused intervals. Keep old completed-session durations as recorded by the previous wall-clock calculation.
5. Regress pause → several days → resume and the unresolved legacy-session path with controlled clocks and Room persistence on device.

Navigating Home does not pause the clock automatically; pause, resume, and finish remain separate actions.
